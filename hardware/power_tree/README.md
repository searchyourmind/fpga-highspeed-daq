# Hypothetical FPGA power-tree reference

**DESIGN ONLY**, separate from both the DAQ RTL simulation and Pi adapter. No FPGA board is selected for implementation or powered. Artix-7 -1 voltage requirements are used only as a concrete rail reference; this is not a complete device power design.

12 V nominal input -> three TPS62130 adjustable buck channels:

| Rail | Nominal voltage | Assumed load | Budget with 25% margin | Feedback top/bottom |
|---|---:|---:|---:|---|
| VCCINT + VCCBRAM | 1.0 V | 2.0 A | 2.5 A | 24.9k / 100k |
| VCCAUX | 1.8 V | 0.4 A | 0.5 A | 124k / 100k |
| VCCO, selected 3.3 V banks | 3.3 V | 0.8 A | 1.0 A | 312k / 100k |

Currents are **design assumptions**, not AMD requirements, an XPE estimate, or measurements. Actual FPGA/package, configured I/O standards, toggle rates, temperatures, XADC and transceiver supplies must be added before a physical design. No DDR termination or SerDes rail is included.

## Component calculation / startup concept
- Regulator: TI TPS62130, 3–17 V input, up to 3 A, 0.8 V feedback reference. Datasheet SLVSAG7F §8–9, tables and application circuit; use its actual minimum/maximum limits for a physical review.
- 2.2 uH initial inductor value, saturation rating to exceed the margin load plus half calculated ripple and separately the worst-case switch-current limit. Nominal 4.5 A minimum Isat is a screening target, not a verified part choice.
- Input: local 2 x 10 uF, 25 V X7R + 100 nF at each regulator. Output: nominal 2 x 22 uF, 10 V X7R. Effective capacitance must be checked using the chosen capacitor's DC-bias curve; simulation uses 44 uF with 10 mOhm combined ESR and is optimistic if derating reduces this.
- Feedback follows Vout=0.8*(1+Rtop/Rbottom). Python checks divider error and computes first-order ripple for the nominal 2.5 MHz example; DCS-Control frequency varies with operating point.
- Sequence concept: core/BRAM -> AUX -> I/O. Use power-good with a compatible always-on logic bias, enable pulldowns, and a sequencer supervising brownout and reverse power-down. PG-to-EN cascading alone does **not** implement all shutdown requirements. Sequencer circuit and worst-case ramp verification are unfinished.
- Input fuse/current limit, reverse-polarity protection, clamping below regulator absolute maximum, and discharge paths are physical-design requirements. They are not claimed implemented by the SPICE circuit.
- Follow the TI hot-loop, feedback quiet-ground and exposed-pad layout guidance. Thermal validation is NOT DONE.

## Reproduce
`make power` executes the original TI average model for DC and small-signal output impedance and executes the original TI transient model for startup/load step. Actual status is in `results/power/power-results.json`; no result is implied by the existence of a netlist.

TI model files are downloaded from the official product page, retain copyright notices, and are excluded from a future public source release pending license review. Fetch them with `python hardware/power_tree/fetch_models.py` when absent. Models are run in ngspice PSpice compatibility mode. A model passing does not certify physical ripple, efficiency, thermal performance, or stability across corners.

## Observed results
Average DC 3.29526846 V and 241-point AC sweep pass. Nine DC load/input cases pass. The compact switching experiment uses 1nF soft start, 0.5A baseline load plus a 0.5A pulse at 0.75ms, and 1.2ms stop time. Full solver trace: 3,002,924 points; final window >1.05ms mean 3.295416634 V, simulated peak-to-peak 4.90747mV. These are not measured hardware ripple specifications. Compact trace and extra load-step/PG checks are generated by `tools/power_evidence.py`. The separate PCB uses a different regulator variant and soft-start capacitor.

The earlier 10nF experiment ended before startup settled and correctly failed the voltage assertion. Switching models are computationally expensive; save only output/PG/inductor vectors. Original logs retain timeouts and failed experiments for traceability.
